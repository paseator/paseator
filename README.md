What I'm working on
YouTube Channel Scanner — a free, open prompt that turns a list from your YouTube Studio into a one-page report: what you have published, how your views are distributed, and one test worth running next.

No installation, no APIs, no account connection. Paste your list, get the report.

How I think about this
Most channel advice starts with what you should do. I prefer to start with what the data already shows, and to be explicit about what it cannot show. Views are not satisfaction. A publish date is not the date those views were earned. A niche is not validated because a list looks coherent.

That is why the tools I build describe before they prescribe.
